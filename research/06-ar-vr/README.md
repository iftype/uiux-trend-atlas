# 06. AR/VR 경험

AR은 현실 위에 정보나 가상 물체를 놓고, VR은 사용자를 몰입 공간 안에 둔다. 가구 배치, 공간 안내, 훈련, 원격 협업처럼 크기와 공간 관계 자체가 정보일 때 가치가 분명하다.

## 대표 패턴

- 내 공간에 제품 배치
- 현실 표면·사물을 따르는 안내
- 360° 투어와 공간형 스토리
- 손·시선·음성을 결합한 직접 조작

## 구현·UX 체크

- 카메라·공간 권한을 요청하기 전에 기능과 데이터 사용 이유를 설명한다.
- 앉은 자세, 좁은 공간, 한 손 사용을 고려한다.
- 멀미를 줄이기 위해 예측 가능한 이동과 안정된 기준면을 유지한다.
- XR 기기가 없을 때 쓸 수 있는 2D 대체 경험을 제공한다.
