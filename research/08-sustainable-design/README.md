# 08. 지속 가능한 디자인

지속 가능한 디지털 디자인은 녹색 이미지를 더하는 일이 아니라 불필요한 페이지, 데이터 전송, 연산, 사용자 시간을 줄이고 오래 유지 가능한 구조를 만드는 일이다.

## 대표 패턴

- 텍스트·기능 중심의 경량 기본 경험
- 사용자가 요청한 뒤 고용량 미디어 로드
- 재사용 가능하고 오래가는 디자인 시스템
- 페이지 무게·전력·탄소 예산

## 구현·UX 체크

- 이미지, 폰트, 자바스크립트 예산을 정하고 CI에서 추적한다.
- 정적 생성, 캐시, 시스템 폰트, 반응형 이미지를 우선한다.
- 저대역폭·저전력 모드에서 핵심 작업을 검증한다.
- 탄소 계산치는 추정치임을 밝히고 실제 전송량·성능 지표와 함께 본다.
