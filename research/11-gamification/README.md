# 11. 게이미피케이션

게임이 아닌 제품에 목표, 진행, 피드백, 선택, 숙련 구조를 적용하는 설계다. 포인트와 배지만 붙이는 방식보다 사용자가 의미 있는 진전과 능력 향상을 느끼는 피드백 루프가 중요하다.

## 대표 패턴

- 명확한 다음 목표와 진행 지도
- 난이도를 선택할 수 있는 도전
- 숙련도와 성취의 시각화
- 경쟁보다 협력에 초점을 둔 사회적 기능

## 구현·UX 체크

- 보상을 제품의 본래 가치와 연결한다.
- 연속 기록이 끊겼을 때 회복 장치를 제공해 수치심과 이탈을 줄인다.
- 단기 클릭뿐 아니라 학습, 완료, 재방문, 장기 만족을 함께 측정한다.
- 압박 알림, 숨은 손실, 강제 공유 같은 다크 패턴을 배제한다.
